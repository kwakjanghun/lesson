 ② 환원: 물질이 산소를 ( 잃는 ) 반응이다.
 ③ 산화 환원 반응의 ( 동시성 ): 한 물질이 산소를 잃고 환원되면 다른 물질이 그 산소를 얻어 산화되므로

 ① 광합성: 식물은 엽록체에서 빛 에너지를 이용하여 물과 이산화 탄소로부터 포도당과 산소를 만든다.
 ⇨ 광합성 반응에서 이산화 탄소는 ( 환원 )되고 물은 ( 산화 )된다.
② 화석 연료의 연소: 화석 연료가 연소하면 ( 이산화 탄소 )와 ( 물 )이 생성되고 많은 에너지가 발생한다.
                    이 에너지를 산업과 교통 수단에서 사용하면서 인류의 삶은 더 풍요로워졌다.
               ⇨ 메테인의 연소 반응에서 메테인은 ( 산화 )되고 산소는 ( 환원 )된다.
 ③ 철의 제련: 자연 상태에서 ( 산화 철 )이 주성분인 철광석으로부터 순수한 철을 얻는 과정
              이때 생성된 철은 각종 기구 제작, 건축물 제작 시 이용 된다.
           ⇨ 산화 철(Ⅲ)과 일산화 탄소의 반응에서 산화 철(Ⅲ)은 ( 환원 )되고 일산화 탄소는 ( 산화 )된다.

 (3) 산소의 이동과 산화 환원 반응의 예
 ① 산화 구리(Ⅱ)와 탄소의 반응
[과정 및 결과]
( 검은색 )의 산화 구리(Ⅱ)와 탄소 가루를 잘 섞어 시험관에 넣고 충분히 가열하면
석회수가 뿌옇게 흐려지면서 시험관 속에 ( 붉은색 ) 물질이 생성된다.
[정리]
∘ 석회수가 뿌옇게 흐려진 까닭: ( 이산화 탄소 ) 기체가 발생했기 때문이다.
∘ 붉은색 물질이 생성된 까닭: ( 구리 )가 생성되었기 때문이다.
∘ 산화 구리(Ⅱ)와 탄소 가루를 가열할 때 일어나는 반응:
검은색 산화구리(Ⅱ)는 산소를 잃고 붉은색의 구리로 ( 환원 )된다. 이와 동시에
탄소는 산소를 얻고 이산화 탄소로 ( 산화 )된다.
 ② 구리판의 가열
[과정 및 결과]
(가)와 같이 구리판을 알코올램프 겉불꽃 속에 넣어 가열하면 ( 검게 ) 변하였고,
(나)와 같이 ( 검게 ) 변한 구리판을 알코올램프의 속불꽃 속에 넣어 가열하면
구리판이 다시 ( 붉게 ) 변하였다.
[정리]
∘ (가)에서 구리판이 검게 변한 까닭: 구리가 산소를 얻어 산화 구리(Ⅱ)로
   ( 산화 )되었기 때문이다.
⇨ 구리와 결합한 산소의 질량만큼 질량이 ( 증가 )한다.
∘ (나)에서 구리판이 다시 붉게 변한 까닭: 산화 구리(Ⅱ)가 산소를 잃고
   붉은색의 구리로 ( 환원 )되었기 때문이다.
⇨ 산화 구리(Ⅱ)에서 떨어져 나간 산소의 질량만큼 질량이 ( 감소 )한다.
∘ 알코올램프의 겉불꽃과 속불꽃
- 겉불꽃: 가장 바깥의 불꽃으로 산소가 충분히 공급되어 속불꽃보다 온도가 ( 높다 ).
- 속불꽃: 안쪽의 불꽃으로 산소가 충분히 공급되지 않아 알코올이 불완전 연소하여 ( 일산화탄소 )가 발생한다.

2. 전자의 이동과 산화 환원 반응
 (1) 전자의 이동에 의한 산화와 환원
 ① 산화: 물질이 전자를 ( 잃는 ) 반응이다.
 ② 환원: 물질이 전자를 ( 얻는 ) 반응이다.
 ③ 산화 환원 반응의 동시성: 한 물질이 전자를 잃고 산화되면 다른 물질이 그 전자를 얻어 환원되므로
                            산화와 환원은 항상 동시에 일어난다.
 ④ 산화 환원 반응과 이동한 전자 수: 산화로 잃은 전자 수와 환원으로 얻은 전자 수는 ( 같다 ).
⇨ 아연(Zn)은 전자를 2개 잃고 산화되었고, 구리 이온(Cu)은 전자를 2개 얻어 환원되었다.
(2) 전자의 이동과 여러 가지 산화 환원 반응
 ① 금속과 금속 염 수용액의 반응: 금속 염 수용액에 반응성이 큰 금속을 넣으면, 반응성이 큰 금속은
                                 전자를 ( 잃고 ) 산화되어 ( 양이온 )으로 되고, ( 양이온 )으로 존재하던
                                 수용액 속 금속 이온은 전자를 얻어 환원되어 금속으로 ( 석출 )된다.
 ∘ 금속(Zn, Cu)은 금속 원자로 존재하며, 금속 염 수용액에는 금속이 양이온의 형태(Cu, Ag)로 존재한다.
 ∘ 금속 염: 금속 이온을 포함하는 이온 결합 화합물로, 수용액에는 해당 금속의 ( 양이온 )이 존재한다.
 ∘ 금속 염 수용액의 색: 대부분의 금속 이온은 수용액에서 색을 나타내지 않으나 Cu은 ( 푸른색 ).
                        Fe은 녹색 등의 색을 나타낸다.
 ∘ 반응이 일어난다는 의미: 금속은 전자를 잃고 금속 양이온이 되어 수용액으로 녹아들고, 수용액에 있던
                            금속 양이온은 전자를 얻어 다시 금속(고체)가 된다.
                            ⇨ ‘석출’된다고 표현하며, 석출은 금속판이나 금속줄 표면에서 일어난다.
 ∘ 금속은 반응성이 클수록 ( 금속 양이온 )의 형태로 있는 것을 선호한다.
    ⇨ ( 산화 )된 게 둘 중 반응성이 더 큰 금속이다.
 ∘ 수용액 속 ( 음이온 )은 반응에 직접 참여하지 않는다.

② 중화점: H과 OH이 모두 반응하여 중화열이 ( 최대로 ) 발생하므로
   중화점에서 온도가 가장 높다.
③ 중화점 이후: 중화 반응이 더 이상 일어나지 않고 처음과 같은 온도의
   NaOH 수용액이 가해지므로 혼합 용액의 온도는 서서히 ( 낮아진다 ).
 (3) 생성 되는 물의 양: 중화점에서 물이 가장 ( 많이 ) 생성된다.
   (예) 일정량의 묽은 염산(HCl) 수용액에 수산화 나트륨(NaOH) 수용액을 가할 경우
① 중화점 이전: 반응한 H 또는 OH 수에 ( 비례 )하여 물 분자 수가 증가한다.
   (단, 혼합 용액의 부피에서 중화 반응으로 생성된 물에 의한 부피 증가는 무시한다.)
② 중화점: 완전히 중화하므로 중화점에서 물 분자가 가장 많이 생성된다.
③ 중화점 이후: 중화 반응이 더 이상 일어나지 ( 않으므로 ) 물 분자수가
   증가하지 않는다.

[염화 칼슘의 용해 반응]
간이 열량계에 물 100g을 넣고 처음 온도를 측정하였더니 25℃였다. 여기에 염화 칼슘(CaCl) 5g을 넣어 녹이면서

→ 염화 칼슘이 물에 용해되는 반응은 에너지를 방출하는 발열 반응이다.
[진한 황산 묽히기]
진한 황산을 묽히는 과정에서는 매우 많은 열에너지가 발생하므로 반드시 다량의 증류수에 진한 황산을
조금씩 넣어가며 묽혀야 한다.
→ 진한 황산이 물에 용해되는 반응은 에너지를 방출하는 발열 반응이다.
 ④ ( 흡열 반응 ): 화학 반응이 일어날 때 주위로부터 에너지를 ( 흡수 )하는 반응이다.
 ⑤ 흡열 반응에서 물질의 에너지와 주위의 온도 변화
 - 반응물이 생성물로 변할 때 에너지가 ( 증가 )하면서 그 차이만큼 에너지가 흡수된다.
 - 반응물의 에너지가 생성물의 에너지보다 ( 작다 ).
 - 화학 반응이 일어날 때 반응물과 생성물의 에너지 차이만큼 주위로 열에너지를 방출하므로
   주위의 온도가 ( 낮아진다 ).

2. 물질 변화에서 출입하는 에너지의 이용
 (1) 발열 반응을 이용하는 일상생활의 예
이용
에너지의 출입
조리용 발열 팩
음식을 데울 수 있는 조리용 발열 팩에는 ( 산화 칼슘(CaO) )과 물(HO)이 
들어있다. 산화 칼슘이 용해될 때 열에너지를 방출하여 주위의 온도가 높아지는 
현상을 이용하는 것이다. 이때 온도가 약 200℃까지 상승하므로
음식물 조리 외에도 살균, 살충에 이용될 수 있다.
CaO + HO → Ca(OH) + 열
연료의 ( 연소 )
연료를 연소시킬 때 열에너지를 방출하여 주위의 온도가 높아지는 현상을
이용하는 것이다. 발생한 열은 난방, 요리, 자동차 운전 등에 이용한다.
일회용 손난로
철(Fe) 가루가 들어 있는 손난로를 흔들면 철이 ( 산소 )와 반응하면서
( 산화 철(FeO) )이 되는 과정에서 열에너지를 방출하여 주위의 온도가
높아지는 현상을 이용하는 것이다.
냉해 예방을 위해 뿌리는 물
과수원에서는 개화 시기에 물을 뿌려 냉해를 예방하기도 하는데, 이는 물이
얼음으로 ( 응고 )하면서 열에너지를 방출하여 주위의 온도가 높아지는 현상을
이용하는 것이다.
 (2) 흡열 반응을 이용하는 일상생활의 예
이용
에너지의 출입
냉찜질 주머니 (냉각팩)
( 질산 암모늄(NHNO) )이 물에 용해될 때 열에너지를 흡수하여 주위의 온도를
낮추는 현상을 이용하는 것이다.
제빵 소다의 열분해
제빵 소다(베이킹 소다)를 넣어 빵을 구우면 ( 탄산수소 나트륨(NaHCO) )이
열에너지를 흡수하여 분해되면서 ( 이산화 탄소(CO) ) 기체가 발생한다.
이로 인해 밀가루 반죽이 점차 부풀어 오르는 현상을 이용하는 것이다.
신선식품 배달용 얼음 주머니
얼음이 물로 ( 융해 )하면서 열에너지를 흡수하여 주위의 온도를 낮추는 현상을 
이용하는 것이다.
 (3) 지구와 생명 현상에서의 에너지 흡수와 방출: 에너지 출입으로 인해 생명이 유지되고 지구에 다양한
     자연 현상이 일어난다.
 ∘ 지구에서 일어나는 에너지의 출입: ( 물 )은 에너지를 흡수하거나 방출하며 지구를 순환한다.
                                    에너지가 흡수되거나 다시 방출되지 않으면 물의 순환은 일어나지 않는다.
