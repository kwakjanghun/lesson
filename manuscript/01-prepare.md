# 1. 준비물

## 1-1. 컴퓨터

| 항목 | 최소 | 권장 | 비고 |
|---|---|---|---|
| 운영체제 | Windows 10 | Windows 11 | 이 자료는 윈도우 기준. 맥도 되지만 화면이 다릅니다 |
| 메모리 | 8GB | 16GB | 렌더할 때 크롬 창 5개가 동시에 뜹니다 |
| 저장 공간 | 10GB 여유 | 20GB | 영상 1편 ≈ 80~200MB |
| 그래픽카드(GPU) | 없어도 됨 | NVIDIA 8GB 이상 | **내 목소리(6장)** 를 내 PC에서 만들 때만 필요. 없으면 Kaggle 무료 GPU로 (6-C) |
| 인터넷 | 필수 | | 클로드는 인터넷으로 동작 |

**학교 PC vs 집 PC**: 설치 권한이 막힌 학교 PC라면 집 PC에 설치하고, 대본 작업은 어디서나(웹 claude.ai) 하고, 렌더만 집에서 하는 방식이 현실적입니다. 자료는 구글 드라이브/USB로 옮기면 됩니다.

## 1-2. 계정

| 계정 | 왜 | 비용 |
|---|---|---|
| **Claude (claude.ai)** | 클로드 코드 사용 | Pro 월 $20 — 클로드 코드는 Pro 이상에서 열립니다 |
| GitHub (선택) | 이 자료의 예제 저장소를 받을 때는 **계정 없이도 됨** | 무료 |
| Kaggle (선택) | GPU 없는 PC에서 내 목소리를 만들 때 | 무료 (휴대폰 인증 필요) |

## 1-3. 설치 순서 지도

| 2장 설치 | → | 3장 | → | 4장 | → | 5장 | → | 6장 |
|---|---|---|---|---|---|---|---|---|
| ① Node.js<br>② Claude 데스크탑 + 로그인<br>③ Python + pip 도구<br>④ ffmpeg, git | | watch 스킬 | | HyperFrames 스킬 + 예제 킷<br>첫 렌더 | | 영상 만들기 | | A 녹음<br>B 로컬 GPU<br>C Kaggle<br>D 교체 |

**순서가 중요합니다.** 특히 ① Node.js 가 없으면 3·4장의 `npx` 명령이 전부 실패합니다.

## 1-4. 이 자료에서 쓰는 폴더 약속

| 폴더 | 용도 | 왜 영문인가 |
|---|---|---|
| `C:\hyper\` | 모든 영상 작업의 뿌리 | HyperFrames는 **한글 경로에서 에러 메시지 없이 멈춥니다** (7장 첫 번째 항목) |
| `C:\hyper\lesson\` | 이 자료의 예제 킷 (깃허브에서 받음) | |
| `C:\hyper\source\` | 선생님의 PDF·녹음·인트로 등 원본 자료 | 한글 파일명은 괜찮습니다. 폴더 경로만 영문이면 됩니다 |
| `C:\hyper\〈영문이름〉\` | 영상 한 편 = 폴더 하나 (예: `chem-redox`) | |
